6 templates · MIT · clone and make it yours

Portfolios that boot,
route, and run.

Six developer portfolio templates, each one built as a machine instead of a landing page — a firmware setup screen, a motherboard, a network topology, a security console, a desktop OS, and a printed manga volume. Every one of them keeps all of its content in one or two data files, so making it yours is an edit, not a rewrite.

01 / FIRMWARE

Developer BIOS Utility

bios

Visitors don't land on a homepage — they boot the machine, watch it detect a developer, and browse the résumé as if editing BIOS settings. Keyboard-driven, no build step, no dependencies.

02 / HARDWARE

CircuitOS

circuitos

An interactive PCB that boots you instead of an OS. The CPU is the engineer; every other component is a section, wired to it with animated copper traces. Plain DOM over an SVG trace layer — crisp at any zoom.

Take one and make it yours

# grab the whole set
git clone __CLONE_URL__
cd __REPO_NAME__/apps/reconos   # or bios, circuitos, net-topology, workspace-os, manga-book

npm install
npm run dev                    # http://localhost:5173

# then edit the data files named in that app's README — nothing else.
npm run build                  # static bundle in dist/, deploy anywhere

bios has no build step at all — python3 -m http.server in its folder and you're running. Each app's own README lists exactly which files hold the content. Everything here is MIT licensed — use it, change it, ship it, no attribution required.
